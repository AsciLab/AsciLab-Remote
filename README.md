# AsciLab Remote

The control app for AsciLab loudspeakers, made by AsciLab. It talks over USB to the Hypex FusionAmp amplifier built into AsciLab speakers — for Mac (macOS 13 or later) and Windows 10/11, no driver needed.

**Download: [Latest release](https://github.com/AsciLab/AsciLab-Remote/releases/latest)**

- Mac: `AsciLab-Remote-<version>.dmg` — notarized by Apple.
- Windows: `AsciLab-Remote-Setup-<version>.exe` — if "Windows protected your PC" appears, click "More info" → "Run anyway".
- Introduction and Quick Start, 11 languages: `AsciLab-Remote-QuickStart.pdf`

Already installed? Use Check for Updates in the app.

Support: Help ▸ Report a Problem… in the app, or admin@ascilab.com

# AsciLab Remote (한국어)

AsciLab 스피커를 컴퓨터와 휴대폰에서 조작하는 앱입니다. AsciLab이 만들었고, AsciLab 스피커에 들어 있는 Hypex FusionAmp 앰프와 USB로 직접 통신합니다. Mac(macOS 13 이상)과 Windows 10·11에서 쓸 수 있으며 드라이버는 필요 없습니다.

**다운로드: [최신 버전](https://github.com/AsciLab/AsciLab-Remote/releases/latest)**

- Mac: `AsciLab-Remote-<버전>.dmg` — Apple 공증을 받은 앱입니다.
- Windows: `AsciLab-Remote-Setup-<버전>.exe` — "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누르세요.
- 소개 및 빠른 시작(11개 언어): `AsciLab-Remote-QuickStart.pdf`

이미 설치했다면 앱의 「업데이트 확인」을 쓰세요.

문의: 앱의 도움말 ▸ 문제 보고… 또는 admin@ascilab.com
